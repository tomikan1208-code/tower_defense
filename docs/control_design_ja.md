# Minecraft Tower Defense 操作・UI設計

Emberwardをミネクラフトで再現するための操作フロー、UI、ホットキー定義。

---

## 1. 全体方針

### 操作パラダイム変更の課題

**Emberward（デスクトップPC）:**
- マウスカーソル自由移動
- ドラッグ&ドロップ配置
- オーバーレイUIで形状プレビュー
- メニュー画面での選択

**Minecraft:**
- プレイヤー視点・手持ちアイテム固定
- 3D空間内での相対配置
- チャット・スコアボード・アクション表示がUI
- 右クリック・左クリック・ホットバーキーが基本操作

### 実装戦略

1. **モード切り替え**: スロット9でトグル
  - スロット1-8: 現在モードの選択枠（最大8種類）
  - スロット9: モード切り替えアイテム（Block <-> Tower）
  - 同一形状ブロックはスタック可能

2. **ブロック配置**: 持ち替え式 + 回転 + 導線表示
  - スロット9でブロックモードへ切り替え → スロット1-8に ブロック形状（最大8種）
   - 右クリック = プレビュー開始（現在位置・敵導線を半透明ブロック＋パーティクルで表示）
  - マウスホイール中心でブロック回転（4方向）
   - 左クリック = 配置確定
  - 配置時にスタック数を1消費

3. **タワー配置**: ホットバー切り替え
  - スロット9でタワーモードへ切り替え → スロット1-8に タワー種（最大8種）
   - 右クリック @ブロック = タワープレビュー + コスト確認
   - 左クリック = 配置確定
  - タワーアイテムは消費しない（無限）

4. **タワー強化**: インベントリGUI
   - タワーを右クリック = インベントリ画面を開く
   - 灰色ガラス板で枠囲み、中央に説明テキスト
   - 緑色ガラス板に「Red強化」「Blue強化」アイコン表示
   - アイテム掴んで（アニメーション）確定

## 2. ホットバー構成とモード切り替え

### ホットバーレイアウト

```
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
│  1   │  2   │  3   │  4   │  5   │  6   │  7   │  8   │  9   │
├──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┼──────┤
│Block1│Block2│Block3│Block4│Block5│Block6│Block7│Block8│Toggle│
│Tower1│Tower2│Tower3│Tower4│Tower5│Tower6│Tower7│Tower8│Mode  │
└──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘

【ブロック配置モード時】
  スロット1-8: ブロック形状（最大8種類）
    例: T字 x3, L字 x2, 正方形 x1 ...
  スロット9: 「Mode Toggle」アイテム

【タワー配置モード時】
  スロット1-8: タワー種（最大8種類）
    例: Basic, Cannon, Frost ...
  スロット9: 「Mode Toggle」アイテム
```

### モード切り替えフロー

```
初期状態: ブロック配置モード
  ↓
スロット9を右クリック（Mode Toggle アイテム）
  ↓
ホットバー内容が切り替わる
  スロット1-8: タワー一覧に切り替え
  ↓
再度スロット9を右クリック
  ↓
ホットバーがブロック一覧へ戻る
```

## 3. ブロック配置フロー

### フェーズ1: モード作動

```
プレイヤーがスロット9「Mode Toggle」で タワーモード → ブロックモード へ
  ↓
ホットバースロット1-8 に ブロック形状（最大8種類）が表示される
  ↓
チャット: "[INFO] ブロック配置モード有効"
```

### フェーズ2: ブロック選択と配置前プレビュー

```
プレイヤーが数字キー「1」-「8」でブロック形状を選択
  ↓
選択したブロック形状がホットバーで強調表示
  ↓
プレイヤーがマップ上を歩き、配置位置を探索
  ↓
右クリック @注視ブロック位置
  ↓
プレビュー表示:
  【敵導線表示】
    - 敵が通過するルート 上の敵歩行パーティクル（青色）を表示
    - このブロックを置いた場合のルート変化を シミュレーション表示
  【ブロック形状表示】
    - 半透明ガラス（緑=配置OK, 赤=配置NG）
    - 各ブロック位置にパーティクルで枠表示
```

### フェーズ3: ブロック回転

```
プレビュー表示中に マウスホイール（UP/DOWN）
  または Q キー（反時計回り）
  ↓
ブロック形状が 90度 回転（時計回りまたは反時計回り）
  ↓
プレビューがリアルタイム更新
  → 敵導線も回転に応じて再計算表示
```

### フェーズ4: 配置確定

```
プレイヤーが「左クリック」で配置確定
  ↓
ブロック形状を実ブロック化
  ↓
同一形状のスタック数を1消費
  （0になったらそのスロットを空にする）
  ↓
チャット通知: "[BLOCK] T字配置完了 | 残り: 2"
```

## 4. タワー配置フロー

### フェーズ1: タワーモード有効化

```
プレイヤーがスロット9「Mode Toggle」で ブロックモード → タワーモード へ
  ↓
ホットバースロット1-8 に タワー種（最大8種類）が表示される
  ↓
チャット: "[INFO] タワー配置モード有効"
```

### フェーズ2: タワーホバー表示

```
プレイヤーが数字キー「1」-「8」でタワーを選択
  ↓
マウスをホットバースロット上に乗せた場合、タイトルに表示：
  "Basic Tower LV1 | Dmg: 4 | Range: 8 | Cost: 15G"
```

### フェーズ3: タワー配置

```
プレイヤーがブロック上に立つ
  ↓
選択したタワーアイテムでブロックを右クリック
  ↓
タワープレビュー表示:
  - 射程範囲を黄色パーティクル円で表示
  - 「コスト 15G で配置します」チャット表示
  ↓
左クリックで配置確定
  ↓
タワーがスポーン（アーマースタンド等で可視化）
  ↓
ゴール -15G、スコアボード更新
  ↓
チャット: "[TOWER] Basic Tower 配置完了（タワーアイテムは消費されません）"
```

## 5. タワー強化フロー（インベントリGUI）

### フェーズ1: 強化メニュー起動

```
ウェーブ中に配置済みタワーを右クリック
  ↓
インベントリ画面が開く
  ↓
タイトル表示: "Tower: Basic Lv.1 | Dmg: 4 | Range: 8"
```

### フェーズ2: GUI レイアウト

```
┌─ Inventory 画面 ─────────────────────────────────────────┐
│                                                           │
│  灰色ガラス板で枠囲み（9 x 3 = 27スロット）              │
│  ┌─────────────────────────────────────────────────────┐ │
│  │ 灰 灰 灰 灰 灰 灰 灰 灰 灰 │ ← ブロック行            │ │
│  │ 灰 [Red] 灰 説 灰 [Blue] 灰 灰 灰 │                  │ │
│  │     強化    明文      強化                          │ │
│  │ 灰 灰 灰 灰 灰 灰 灰 灰 灰 │                         │ │
│  └─────────────────────────────────────────────────────┘ │
│                                                           │
│  中央に緑色ガラス板パネル：                               │
│    "Red: ダメージ +2 | コスト 15G"                       │
│    "Blue: 範囲 +1 | コスト 15G"                         │
│    "Lv1 → Lv2 へ強化します"                            │
│                                                           │
└───────────────────────────────────────────────────────────┘

配置位置:
  - Red強化タイル: 左中央（スロット 11）
  - Blue強化タイル: 右中央（スロット 15）
  - 説明テキスト: 中央（スロット 13、ガラス板ブロック）
```

### フェーズ3: 強化実行

```
プレイヤーが Red/Blue タイル (スロット11 or 15) をドラッグかクリック
  ↓
アイテムが掴める アニメーション表示
  ↓
選択したアイテムを DROP（左ボタン解放）
  ↓
強化確定
  ↓
インベントリが閉じる
  ↓
ゴール消費 + タワー Lv. 更新
  ↓
チャット: "[TOWER] Basic Tower Lv.1 → Lv.2 Red強化完了 | Dmg: 4 → 6"
```

### フェーズ4: 複数強化との管理

```
同じタワーを複数回強化可能
  ↓
強化するたびに Red/Blue GUIが更新される
  例: Basic Lv.1 → Lv.2 (Red) → Lv.3 (Blue)
  ↓
各パス を追跡表示
```

## 6. 実装対象： ホットキー・アクション一覧

| キー | 機能 | コンテキスト |
|------|------|----------|
| **スロット1-8** | ブロック形状 / タワー種選択（数字キー）| モードに応じて表示 |
| **スロット9** | モード切り替え（Block <-> Tower） | 常時表示 |
| **右クリック** | ブロック/タワープレビュー開始 | 配置モード中 |
| **左クリック** | ブロック/タワー配置確定 | プレビュー中 |
| **マウスホイール** or **Q** | ブロック回転（±90度） | ブロックプレビュー中 |
| **右クリック（タワー上）** | 強化メニュー（インベントリ）を開く | ウェーブ中・タワー上 |
| **ドラッグ** | インベントリ内でアイテム掴み | 強化メニュー表示時 |
| **DROP**（左ボタン解放） | 強化確定 | 強化タイル上 |

### 技術注記（Minestomサーバー実装）

- マウスホイール回転: 実装可能（スロット変更イベントで検知）
- Qキー回転: 実装可能（ドロップイベントを回転入力として再解釈）
- Eキー回転: 非推奨（通常はインベントリを開くため競合）
- 推奨: 「マウスホイール + Q」または「マウスホイール + Sneak+右クリック」

## 8. エラーハンドリング

### ブロック配置エラー

| エラー | メッセージ | 対応 |
|--------|-----------|------|
| 重配置 | 「ここは既にブロックがあります」 | キャンセル推奨 |
| 場外 | 「マップ外です」 | 位置修正 |
| リソース不足 | 「ブロックがありません」 | 別形状を選択 |

### タワー配置エラー

| エラー | メッセージ | 対応 |
|--------|-----------|------|
| ブロック不足 | 「ブロックの上にしか配置できません」 | ブロック先に配置 |
| コスト不足 | 「ゴール不足です」 | 敵撃破して溜める |
| 重配置 | 「ここは既にタワーがあります」 | 別位置へ |

## 9. 実装例：コマンド/イベント案

### Minestom:

```java
// ホットバー選択イベント
player.getInventory().onSlotChange(slot, item);
  → BlockPlacementManager.onBlockSelect(player, slotNumber);

// 右クリックイベント
PlayerHandInteractEvent.onInteract()
  → if (block != null) {
        if (isBlockInPreview) {
          BlockPlacementManager.showPreview(block);
        } else {
          TowerPlacementManager.showMenu(block);
        }
    }

// 左クリックイベント
PlayerHandInteractEvent.onBlockBreak() [抑制]
  → if (isBlockInPreview) {
        BlockPlacementManager.confirmPlace(block);
    }

// チャット通知
player.sendMessage(Component.text("[TOWER] Basic Tower 配置完了"));
```

## 10. 優先度順の実装例

### P1 (必須)
- ブロック配置の基本フロー（1-8キー + 右左クリック）
- タワー配置の基本フロー（1-8キー + 右クリック確定）
- スコアボード表示

### P2 (重要)
- 強化メニュー（R/B分岐）
- ゴール消費ロジック
- エラーメッセージ

### P3 (快適性)
- プレビュー表示の可視化（パーティクル）
- 配置可否判定の色分け（緑/赤）
- ホットキーリマップ機能

### P4 (後付け)
- 設定UIでホットキー変更
- キーバインド保存
