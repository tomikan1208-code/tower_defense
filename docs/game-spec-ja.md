# RogueLike Tower Defense 仕様メモ (Emberward 参考)

## 1. ゲームコンセプト

- Minestomで動く、ローグライク進行型のTower Defense。
- 侵攻経路をプレイヤーがブロック配置で変えながら防衛する。
- タワーは自由配置ではなく、配置可能条件を満たす場所に置く。

## 2. コアルール

- プレイヤーは特定の形ブロックを有限個だけ所持する。
- ブロック形状例:
  - L字
  - T字
  - 四角
  - 十字
- ブロックは敵の侵攻を妨害できる。
- ただし、敵の進路を完全封鎖する配置は不可にする。
- 敵はスポーン地点からコアまで最短経路で進行する。
- 現在の最短経路は赤い線パーティクルで可視化する。
- タワーは上記ブロックの上にのみ設置できる。

## 3. 進行フロー

- ロビー
  - 華やかな装飾付きの待機エリア。
  - ゲームスタート用の門を設置。
- ロードマップ
  - 門から遷移後、マス選択画面を表示。
  - マス種別: 通常 / 精鋭 / イベント / ボス。
  - 各マスは3x3ブロックで表現し、中央ブロックをクリックして選択。
- ステージ
  - 選択マスに応じたマップを生成。
  - 例: 森 / 砂漠 / 雪。
  - 遷移直後に準備時間を開始。
  - 準備時間中にプレイヤーはブロック配置と防衛準備を行う。

## 4. 実装優先順

- 第1段階 (今回の基盤):
  - ロビー生成
  - スタート門
  - ロードマップ画面
  - 3x3マスクリックでステージ遷移
  - ステージごとのテーマ地形と準備時間
- 第2段階:
  - 形ブロック配布システム
  - 有限インベントリ管理
  - 最短経路探索と赤線パーティクル表示
  - 完全封鎖禁止判定
- 第3段階:
  - ブロック上限定のタワー設置
  - 敵AI、ウェーブ、報酬、ローグライク強化

## 5. いまの合意事項

- 最初にロビー導線を作る。
- ブロック形状・経路妨害・経路可視化は次フェーズで実装する。
- ロードマップ経由で各ステージへ進む体験を先に成立させる。
