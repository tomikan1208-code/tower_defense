数値を変えると、どこに書かれるか
保存すると ai/balance.py（AI 学習のシミュレータ）と src/…/*.java（実際のゲーム）の両方に同じ値を書きます。 片方だけ変えると、学習した方策が実ゲームで通用しなくなるためです。
書いたあとに balance.py の構文確認と Java との突き合わせまで通し、 ずれていたら全ファイルを元に戻します。1 つでも失敗したら 1 文字も書きません。
実ゲームに反映するにはビルドとサーバー再起動が必要です。 学習側は次に開始したときから新しい値になります。
対象外: 送還・呪詛・支援の効果量（Effect）、見た目・音・説明文、 形状や属性などの種別。数値ではないか、突き合わせで検算できないため。

⚙️ 学習設定
世代数に 0 を入れると上限なしで、停止ボタンを押すまで回り続けます。 停止は即殺しではなくいまの塊を終えて保存してから止まるので、 押してから実際に止まるまで数十秒かかることがあります。
カリキュラム（盤面の広さ・人数・送れるモンスターの種類）の進み方は 世代数とは別で、既定では 40 世代で 1 周します。 変えたいときは環境変数 MAZEWARD_CURRICULUM_GENS。
0 なら試合を時間で打ち切りません。誰かが脱落して決着したときだけ 終わります（世代の打ち切りが最後の歯止め）。
値を入れるとその分で強制終了しますが、15 分未満にするとサドンデス （漏れダメージ2倍）が発動しなくなるので注意してください。
世代の区切りは固定ステップ数ではなく試合の切れ目で決めます。 1 ステップ = ゲーム内 1 秒。
「ゲーム内 30 分以下なら完了率 100%」「30 分以上なら 90%」 「60 分超えで打ち切り」が既定です。
環境数は空欄なら実機に合わせて自動で決まります（この環境は numpy で CPU 側を回すので、VRAM ではなく論理コア数から決めます）。
ドメインランダム化は、試合ごとに塔・敵・経済の数値へ ±この割合の スケールを掛けます。0 にすると素の数値だけで学習しますが、 バランスを変えたときに方策が壊れやすくなります。
