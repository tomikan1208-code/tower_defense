⚙️ 学習設定
0 なら試合を時間で打ち切りません。誰かが脱落して決着したときだけ 終わります（世代の打ち切りが最後の歯止め）。
値を入れるとその分で強制終了しますが、15 分未満にするとサドンデス （漏れダメージ2倍）が発動しなくなるので注意してください。
世代の区切りは固定ステップ数ではなく試合の切れ目で決めます。 1 ステップ = ゲーム内 1 秒。
「ゲーム内 30 分以下なら完了率 100%」「30 分以上なら 90%」 「60 分超えで打ち切り」が既定です。
環境数は空欄なら実機に合わせて自動で決まります（この環境は numpy で CPU 側を回すので、VRAM ではなく論理コア数から決めます）。
ドメインランダム化は、試合ごとに塔・敵・経済の数値へ ±この割合の スケールを掛けます。0 にすると素の数値だけで学習しますが、 バランスを変えたときに方策が壊れやすくなります。
